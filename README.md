## Tasks Completed

### Task 1: Dataset Visualization
- **Objective:** Explore and visualize the Iris dataset using EDA techniques
- **Dataset:** Iris Dataset (seaborn) — 150 samples, 3 species, 4 features
- **Tools:** Python, pandas, matplotlib, seaborn
- **Key Findings:** Petal length and petal width are the most powerful features for distinguishing species. Setosa is
 clearly separable from Versicolor and Virginica

### Task 2: Stock Price Prediction
- **Objective:** Predict next day closing price of Apple (AAPL) stock
- **Dataset:** Yahoo Finance via yfinance — 501 trading days (2022–2024)
- **Model:** Linear Regression
- **Results:** MAE: $1.72 | R² Score: 0.9345
- **Key Finding:** Short term stock prices follow strong momentum patterns.Predicted prices closely follow actual prices
with slight lag during sharp market movements

### Task 3: Heart Disease Prediction
- **Objective:** Predict heart disease risk from clinical health data
- **Dataset:** Heart Disease UCI Dataset (Kaggle) — 1025 patients, 14 features
- **Models:** Logistic Regression, Random Forest, Decision Tree
- **Best Result:** Logistic Regression — 86.15% CV Accuracy | AUC: 0.90
- **Key Finding:** Chest pain type, maximum heart rate, and thalassemia are the strongest predictors of heart disease risk

### Task 5: Mental Health Support Chatbot
- **Objective:** Fine-tune a language model to provide empathetic responses for mental health support
- **Dataset:** Mental Health Counseling Conversations (HuggingFace)
- **Model:** DistilGPT2 fine-tuned using HuggingFace Trainer API
- **Training:** 2 epochs, 1000 samples, T4 GPU on Google Colab
- **Key Finding:** Even minimal fine-tuning on domain-specific data teaches the model to structure responses in a therapist
 tone

### Task 6: House Price Prediction
- **Objective:** Predict house sale prices from property features
- **Dataset:** House Prices Advanced Regression Techniques (Kaggle) — 1460 houses, 81 features
- **Model:** Gradient Boosting Regressor
- **Results:** MAE: $19,139 | RMSE: $28,810 | R² Score: 0.8918
- **Key Finding:** Overall quality rating and living area are the two most dominant factors in predicting house prices
